# Kmods 软件源工作流程图

## 📊 完整流程可视化

```
┌─────────────────────────────────────────────────────────────────┐
│                    GitHub Actions Workflow                       │
│                  (Build iStore OS for fine3399)                  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  Step 1: 编译固件 (Compile Firmware)                             │
│  - 编译 iStoreOS 固件                                             │
│  - 同时编译所有内核模块 (916个 kmod-*.ipk)                        │
│  - 生成到: bin/targets/rockchip/armv8/packages/                 │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  Step 2: 生成 kmods 软件源 (NEW!)                                │
│  ┌──────────────────────────────────────────────────────┐       │
│  │ 2.1 收集 kmod 包                                      │       │
│  │     → 从 bin/targets/.../packages/ 复制所有 kmod-*.ipk│       │
│  │     → 组织到 kmods-repository/packages/aarch64/      │       │
│  └──────────────────────────────────────────────────────┘       │
│                              ↓                                   │
│  ┌──────────────────────────────────────────────────────┐       │
│  │ 2.2 生成软件源索引                                    │       │
│  │     → 生成 Packages 文件                              │       │
│  │     → 压缩为 Packages.gz                              │       │
│  │     → 包含包名、版本、架构、SHA256 等信息              │       │
│  └──────────────────────────────────────────────────────┘       │
│                              ↓                                   │
│  ┌──────────────────────────────────────────────────────┐       │
│  │ 2.3 创建 README 文档                                  │       │
│  │     → 生成使用说明                                     │       │
│  │     → 包含部署和配置示例                               │       │
│  └──────────────────────────────────────────────────────┘       │
│                              ↓                                   │
│  ┌──────────────────────────────────────────────────────┐       │
│  │ 2.4 打包归档                                          │       │
│  │     → 创建 kmods-repository.tar.gz                    │       │
│  │     → 生成 SHA256 校验文件                            │       │
│  └──────────────────────────────────────────────────────┘       │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  Step 3: 清理并复制固件                                          │
│  - 复制固件镜像到 output/                                        │
│  - 复制 kmods 归档到 output/                                     │
│  - 生成所有文件的 SHA256 校验和                                  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  Step 4: 上传到 GitHub Release                                   │
│  📦 发布内容：                                                    │
│  ├─ istoreos-rockchip-armv8-fine3399-*.img.gz (固件)            │
│  ├─ kmods-repository-fine3399-aarch64_cortex-a53.tar.gz (NEW!)  │
│  ├─ *.sha256 (校验文件)                                          │
│  └─ Release 说明包含 kmods 使用指南                              │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                      用户下载和部署                               │
└─────────────────────────────────────────────────────────────────┘
```

## 🚀 用户使用流程

```
┌─────────────────────────────────────────────────────────────────┐

                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  2. 解压归档                                                      │
│     tar -xzf kmods-repository-*.tar.gz                           │
│                                                                   │
│     生成目录结构：                                                │
│     kmods-repository/                                            │
│     ├── README.md                                                │
```

## 📊 关键时间节点

| 阶段 | 时间消耗 | 说明 |
|------|---------|------|
| 固件编译 | ~60-120分钟 | 主要时间消耗（不变） |
| Kmods 收集 | ~10-30秒 | 复制 .ipk 文件 |
| 索引生成 | ~5-10秒 | 生成 Packages.gz |
| 打包归档 | ~30-60秒 | 创建 tar.gz |
| **总额外时间** | **~1分钟** | ✅ 几乎可忽略 |
